# @indaba/tui

A terminal dashboard for [Indaba](https://github.com/yaotzin1/indaba) runs, built on Ink: follow a run live, or replay one from its files.
Optional: `indaba` works without it.

```bash
npm install -g indaba@next @indaba/tui@next
```

```bash
indaba run workflow.ai.yml --tui   # run, and show it as a dashboard
indaba watch                       # list the runs, or follow one
```

It reads only what a run writes, and starts and stops nothing. It also edits the project's logging settings for
`indaba settings`.

More in [Getting started](https://yaotzin1.github.io/indaba/getting-started.html).
