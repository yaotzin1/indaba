What this screen shows

  • Health says what is wrong before a run fails: a missing agent, a missing API key, an unreachable server, a container engine that is not running. 1 missing opens to the one thing to do (AC-14, AC-15; it needs specs/agent-sandbox).
  • Last result and Last cost come from the latest run of that workflow, and read like the Runs screen (unknown, at least, no model calls).
  • New workflow opens the wizard of specs/workflow-editor; Copy to another project makes a draft for the editor; Import a folder adds a folder to the places Indaba looks, and shows the resolved folder for confirmation first (spec section 6).
  • Every action that changes something is an explicit user action, and a destructive one names what will happen and asks (AC-13).
