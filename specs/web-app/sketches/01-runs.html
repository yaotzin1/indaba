Sketch 1 of 6, sample data. Delivery step 1: a list of runs, not of workflows (the registry is a later step). Rows come from GET /api/v1/runs; the table updates from GET /api/v1/events without a reload. The cost column needs a cost on RunSummary, which it does not have today (question 1 in the README). The table is an apsw-gridwright grid (through apsw-gridwright-mui): sorting, selection and paging are its defaults; search, column filters, column layout and density are its add-ons, which this screen switches on. The grid is a real <table> with role="grid" and a live region, so keyboard and screen-reader support are the grid's.

What this screen shows

  • State is always a word and a symbol, never colour alone (AC-07, AC-20).
  • A cost that cannot be computed reads unknown; a total that includes one reads at least and (partial); a run with no model call reads $0.00 (no model calls) (AC-19).
  • A run that did not record its workflow name shows that, not an empty cell.
  • Rows are links; the whole screen works with the keyboard; the table scrolls sideways below 640 px instead of cutting columns.
